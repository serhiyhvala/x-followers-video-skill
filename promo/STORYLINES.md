# Storylines for the skill's launch film (16:9, silent)

The one thing: **your follower milestone becomes a video your followers see themselves in, from one
data.json, with one skill.** The viewer remembers: "I can make that for my 500."

The spine: @serhiyhvala's real profile at 221 followers, the real 60 newest followers, the real 7-day
numbers, through install → collect → build → the four rendered videos.

## A. The number leaves the page (recommended: a stranger follows a real screen, and the install command is the payoff they can copy)

Device: a number lands. Form: object-to-object chain. The real profile fills the frame; the camera pushes
to "221 Followers"; the number lifts off the page as a title ("221 people hit follow."), then drops into
`{ "milestone": 221 }` in a terminal where the install and build commands type themselves; the render's
last line opens into the wall film playing full frame; the other three templates cut in; the claim lands;
the end card is the install command.
First two seconds: the real x.com profile, already pushing in; "221 Followers" underlines in orange at 0.9 s.
Beats: hook (profile) → tension ("A post says thanks. This shows them.") → reveal (the skill's name) →
proof (install, collect, build, render as four typed verbs) → payoff (wall, then mosaic, receipt,
terminal) → claim ("Every follower sees themselves.") → end card (`npx skills add …`).
Look: white ground, Inter 900, one accent #FF5A1F; the terminal is the template's own dark window on
#D9DDE3; every "product" frame is a real screenshot or a real render.
Sound: none by request; type and motion carry it.

## B. The result first

Device: the result first. Form: an endless zoom. Frame 0 is the wall finale (221 inside the rings) playing
full frame; the camera pulls back to find it inside a terminal's `renders/wall-16x9.mp4`, then further
back to the `data.json`, then to the real profile page the number came from; then the film runs forward
again through install and build to all four templates.
First two seconds: the rings spiral out around 221, full frame.
Beats: payoff first → pull back → origin → the verbs → the four templates → claim → end card.
Look: as A. Sound: none.

## C. Type carries the argument

Device: type carries the argument. Form: cut on the beat. Giant lines on alternating colour fields
borrowed from the four templates (white/orange, yellow, green, dark): "221 followers." / "60 faces." /
"7 days." / "One command." / "Four films."; each field is a template playing behind the words.
First two seconds: "221" fills the frame on orange; cut to the wall rings.
Beats: five claims, five cuts → the templates → end card.
Look: the templates' own palettes; Inter 900 at 20% of the frame height. Sound: none.
